## ติดตั้ง

> ใช้ฐานข้อมูลแยกสำหรับระบบนี้ — อย่ารัน schema ลงฐานข้อมูลของแอพอื่น (ชื่อตารางอาจชนกัน เช่น `positions`)

1. สร้างฐานข้อมูล PostgreSQL ใหม่ (เช่น Neon project หรือ database ใหม่)
2. รัน `db/schema.sql` แล้วตามด้วย `db/seed.sql` (ข้อมูลเริ่มต้น: บริษัท, ระดับ/ตำแหน่ง, รายได้/รายหัก, กะ, ประเภทการลา, วันหยุดปี 2026, บทบาทและสิทธิ์)
3. ตั้งค่า environment variables ตาม `.env.example`
   - `DATABASE_URL` — connection string
   - `SESSION_SECRET` — สตริงสุ่มยาว ๆ
   - `CRON_SECRET` — สำหรับงานรายวัน (Vercel Cron ส่งให้อัตโนมัติ)
   - `DB_DRIVER=pg` — ถ้าใช้ PostgreSQL ทั่วไปแทน Neon
4. `npm install` แล้ว `npm run dev`
5. เปิด `/setup` เพื่อสร้างผู้ดูแลระบบคนแรก แล้วเข้าสู่ระบบด้วยอีเมลหรือรหัสพนักงาน

## ข้อควรตรวจสอบก่อนใช้งานจริง

- ไฟล์ส่งหน่วยงาน (สปส.1-10, ภ.ง.ด.1/1ก/3, ไฟล์โอนธนาคาร, กท.20ก) ออกเป็น CSV ตามคอลัมน์มาตรฐาน — ตรวจรูปแบบกับระบบ e-Filing / ธนาคารที่ใช้จริงก่อนยื่น
- อัตราประกันสังคม, เพดานภาษี และวันเริ่มกองทุนสงเคราะห์ลูกจ้าง ตั้งค่าได้ที่ ตั้งค่า → อัตราตามกฎหมาย
- ถ้าเริ่มใช้ระบบกลางปี ให้กรอก “เงินสะสมยกมา” (เงินได้/ภาษี/ประกันสังคม/PF ที่จ่ายไปแล้วในปีนั้น) ที่ พนักงาน → เงินเดือน → ลดหย่อน ก่อนคำนวณงวดแรก ไม่เช่นนั้นภาษีหัก ณ ที่จ่ายจะประมาณการต่ำกว่าจริง
- ก่อนสร้างงวดเงินเดือน ต้องตั้ง “รอบการจ่ายเงินเดือน” ให้แต่ละประเภทการจ้างที่ ตั้งค่า → รอบเงินเดือน
- รหัสผ่านเก็บแบบ scrypt (`salt:hash`) ดู `lib/auth.ts`

## โครงสร้างโค้ด

- `db/` — schema และ seed
- `lib/` — engine หลัก: `attendance.ts` (เวลาทำงาน), `leave.ts` (สิทธิ์การลา), `workflow.ts` (สายอนุมัติ), `personnel.ts` (การดำเนินการ), `payroll.ts` (เงินเดือน/ภาษี), `reports.ts` (รายงาน), `print.tsx` (เอกสารพิมพ์)
- `app/(app)/` — หน้าจอหลัก, `app/print/` — เอกสารสำหรับพิมพ์/PDF, `app/api/` — ไฟล์ดาวน์โหลดและ cron, `app/actions/` — server actions
