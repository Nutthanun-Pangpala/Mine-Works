# ระบบ HR

เว็บแอพบริหารงานบุคคลภายในองค์กร สร้างด้วย Next.js (App Router) และ PostgreSQL

## ฟีเจอร์ที่มีแล้ว

- เข้าสู่ระบบ และสิทธิ์ 4 ระดับ: ผู้ดูแลระบบ, ฝ่ายบุคคล, หัวหน้างาน, พนักงาน
- ทะเบียนพนักงาน และโครงสร้างองค์กร (สาขา แผนก ตำแหน่ง กะ)
- ลงเวลาเข้า–ออกงานผ่านเว็บ พร้อมพิกัด GPS และตรวจระยะห่างจากสาขา
- ใบลา พร้อมโควตาวันลาและสายอนุมัติ (หัวหน้า หรือฝ่ายบุคคล)
- คำขอ OT พร้อมอนุมัติ
- วันหยุดบริษัท
- แดชบอร์ด และรายงาน CSV (สรุปรายเดือน, ลงเวลา, ลา, OT, ทะเบียนพนักงาน)

## ยังไม่ได้ทำ

เงินเดือน/สลิป, เบิกค่าใช้จ่าย, ประเมินผล, สรรหา, คอร์สเรียน, เชื่อมเครื่องสแกนนิ้ว

## ติดตั้ง

1. สร้างฐานข้อมูล PostgreSQL แล้วรัน `db/schema.sql`
2. ตั้งค่า environment variables ตาม `.env.example`
3. `npm install` แล้ว `npm run dev`

รหัสผ่านเก็บแบบ scrypt (`salt:hash`) ดู `lib/auth.ts`
